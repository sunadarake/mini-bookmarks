# 並び替え機能（日時・タイトル・サイト・手動）

## 概要
一覧の並び順を select で切り替えられるようにする。新しい順/古い順は `createdAt` を基準にし、タイトル順・サイト順（昇順）と、保存配列順の「手動順」を用意する。選択は設定に保存して popup とフルタブ画面の両方に適用し、ドラッグ&ドロップは手動順のときだけ有効にする。

## 調査結果
- 現状は並び替え UI・ソート処理がなく、`currentItems` の配列順で描画している。追加時は `addItem` が先頭に挿入し、`moveItem` で手動並び替えしている
- `src/lib.js` の `setupListView` が popup / フルタブ画面共通の一覧初期化で、`render()` が `renderItems` を呼ぶ
- `settingsGet` / `settingsSet` は `DEFAULT_SETTINGS` をマージする。`src/options.js` は `settingsSet({ confirmDelete })` で設定を丸ごと上書きしている
- 記事データに日時フィールドはない
- `renderItems` の `canReorder` は `!keyword && !favoritesOnly`
- テストは `tests/lib.test.js` が対象

## 決定事項
- 並び順は「新しい順」「古い順」「タイトル順」「サイト順」「手動順」の5種類
- 新しい順/古い順は `createdAt` 基準。既存項目は現在時刻で一括補完
- タイトル・サイトは昇順のみ
- 選択は設定に保存し、popup / フルタブ両方に適用
- ドラッグは手動順のときだけ有効
- UI は select
