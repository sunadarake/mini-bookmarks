# サイトの部分入力・select による絞り込み

## 概要
popup とフルタブ画面にサイト専用の入力欄とサイト選択の select を追加し、`rootUrl` の部分一致・選択サイトの一致で一覧を絞り込む。タイトル検索・お気に入り絞り込みとは AND で併用する。

## 調査結果
- `src/lib.js` の `filterItems(items, keyword, favoritesOnly)` はタイトルの部分一致とお気に入り絞り込みのみ
- `setupListView` が検索入力・お気に入り切替を管理し、`render()` が `search` の値と `favoritesOnly` を `renderItems` に渡す
- `rootUrl` は TODO 00012 で保存される
- select の選択肢は保存済み項目から生成する必要がある
- ドラッグ可否は `renderItems` の `canReorder` で制御している

## 決定事項
- サイト入力は `rootUrl` への部分一致、select は完全一致
- 入力と select は AND
- タイトル検索・お気に入りとも AND
- UI は popup とフルタブ画面の両方に専用入力欄＋select を置く
- 絞り込み状態は保存しない

## 懸念点・未決事項

- `rootUrl` が空の項目（`chrome://` など）は入力・select の対象外。ただし「すべてのサイト」では表示する
