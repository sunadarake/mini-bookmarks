# お気に入り機能（星ボタン・一覧切替）

## 概要
記事を後で見直せるようお気に入りに追加できるようにする。各記事の削除（✕）の左に星ボタンを置き、押下で toggle して色を変える。popup とフルタブ画面の検索窓の上に「すべて」「お気に入り」のタブ型ボタンを置き、一覧を切り替える。

## 調査結果
- `src/lib.js` の `renderItems` が `read-mark`・リンク・削除ボタンを組み立てている
- `filterItems(items, keyword)` はタイトルの部分一致のみ
- 記事要素は `{ url, hostName, title, read }`（`src/lib.js`）
- popup / tab は `render()` で `renderItems(currentItems, search値, handlers)` を呼ぶ
- `src/common.css` に `.section`、`.btn`、`.delete-btn` などがある

## 決定事項
- お気に入りにしても通常一覧には表示したままにする
- 星ボタンと一覧切替は popup・フルタブ画面の両方に付ける
- 切替 UI は検索窓の上に「すべて」「お気に入り」のタブ型2ボタン
- 手動確認（Chrome 上での操作）はこの環境では未実施
