# 絵文字アイコンを Lucide に置き換える

## 概要
UI でアイコンとして使っている絵文字・記号（`↗` `☰` `✅` `✕` `▾`）を Lucide のインライン SVG に置き換え、見た目を統一する。外部 CDN は Manifest V3 の CSP とビルドなし構成に合わないため、SVG は同梱する。

## 調査結果
- `src/popup.html:18` に `↗`（フルタブ画面を開く）、`src/popup.html:26` に `☰`（オプション）
- `src/tab.html:19` に `☰`（オプション）
- `src/lib.js:160` に `✅`（既読マーク）、`src/lib.js:179` に `✕`（削除）、`src/lib.js:229` に `▾`（サイト絞り込みのキャレット）
- `src/common.css` に `.site-select-caret` / `.read-mark` / `.delete-btn` / `.menu-btn` のスタイルがある。検索欄は既に Lucide 風のインライン SVG を data URI で使用している
- `tests/lib.test.js:423,440,442` が `.read-mark` の `textContent` を `✅` で検証している
- `README.md:47-49` が `✕` `↗` `☰` を操作説明に記載している
- `build.sh` は `src/` をそのまま zip に入れる。ビルド工程・外部依存はない

## 決定事項
- 置き換え対象はアイコン記号すべて（`↗` `☰` `✅` `✕` `▾`）。「Add +」の `+` はテキストのまま残す
- 割り当ては `↗`=external-link、`☰`=menu、`✅`=circle-check、`✕`=x、`▾`=chevron-down
- 外部読み込みは Manifest V3 の CSP とビルドなし構成に合わないため、Lucide の SVG をインラインで同梱する
