# 記事検索欄のプレースホルダーを「記事タイトルを検索...」に変更

## 概要
popup とフルタブ画面の記事検索欄のプレースホルダーが現状 `Search...` になっている。検索対象が記事タイトルであることを分かりやすくするため `記事タイトルを検索...` に変更する。

## 調査結果
- `src/popup.html:28-33` の `id="search"` 入力欄に `placeholder="Search..."` がある
- `src/tab.html:26-31` の `id="search"` 入力欄にも同じ `placeholder="Search..."` がある
- プレースホルダーは JS から参照されておらず、HTML の属性変更だけで完結する
- `README.md` / `AGENTS.md` にプレースホルダー文字列の記載はない
