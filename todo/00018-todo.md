# 一覧にページング（無限スクロール）を追加する

## 概要
現在は保存済みの全記事を一度に `renderItems` で描画しているため、1000 件規模になると初期描画がもたつく。popup / フルタブ画面の一覧を最初に 100 件だけ描画し、一覧末尾付近までスクロールしたら 100 件ずつ追加描画する。

## 調査結果
- `src/lib.js`
  - `renderItems` が `filterItems` の結果を全件 DOM 生成している（`renderItems` 内 `filterItems(items, keyword, siteUrl).forEach(...)`）
  - `setupListView` が検索・並び替え・サイト絞り込み・削除・追加のたびに `render()` で全件を再描画している
  - `document.getElementById("total-count")` には全件数（`items.length`）を表示している
- `src/popup.html` / `src/tab.html` は `#bookmark-list` の直後にスクロール検知用の要素を持たない
- `src/common.css` に一覧のスタイルがある
- `tests/lib.test.js` に `renderItems` の jsdom テストがある
- popup / フルタブ画面は共通で `setupListView` を使うため、両方に同じ挙動を入れられる

## 決定事項
- 最初の表示件数と追加読み込みの単位は 100 件ずつ
- 検索・並び替え・サイト絞り込みを変えたときは最初の 100 件に戻す
- `Total` の表示は従来どおり全件数
