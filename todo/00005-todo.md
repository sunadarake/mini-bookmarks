# ハンバーガーメニューからオプションを開く

## 概要
popup とフルタブ画面にハンバーガーボタンを置き、押すとオプション画面を開く。popup 左上の既存の↗（フルタブを開く）は残し、その右にハンバーガーを追加する。

## 調査結果
- `src/popup.html` の `.header-left` には↗ボタン（`open-tab-btn`）がある
- `src/tab.html` の `.header-left` には `total-count` のみで、ボタンは無い
- `src/popup.js` は `chrome.tabs.create` で `src/tab.html` を開いている
- オプション画面は TODO 00004 で新設される（`src/options.html`、manifest の `options_ui`）
- ヘッダーは `common.css` の `.header` グリッドで構成されている

## 実装計画
