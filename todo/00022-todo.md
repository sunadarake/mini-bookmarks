# 一度に表示する記事数を設定できるようにする

## 概要
記事一覧で一度に表示する記事数（スクロールで追加読み込みする単位）を、オプション画面から変更できるようにする。既定は 30 記事で、10 記事単位・最大 100 記事まで設定可能にする。

## 調査結果
- `src/lib.js` の `PAGE_SIZE`（現在 100）が初回描画と追加読み込みの件数。`setupListView` が `settingsGet()` の結果を読んでいる
- 設定は `chrome.storage.local` の `MiniBookMark_Settings` に保存し、既定値は `DEFAULT_SETTINGS`（`confirmDelete` / `sortMode`）
- オプション画面は `src/options.html` / `src/options.js`。設定は `.section` 内の `.setting-row`（チェックボックス）で、スタイルは `src/common.css`
- 一覧側のページングは `setupListView` の `visibleCount` と `IntersectionObserver` で、`PAGE_SIZE` ずつ増やしている
- ページングのテストは `tests/lib.test.js` の `setupListView のページング` にあり、`PAGE_SIZE` を基準に期待値を書いている

## 決定事項
- 設定 UI はプルダウン（10〜100 を 10 記事単位）
- 設定できる上限は 100 記事
- ページ番号 UI は追加せず、既存のスクロール追加読み込みの単位を設定値にする
