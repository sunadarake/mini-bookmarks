# テスト・lint の成功時出力を簡潔にする

## 概要
`npm test` の成功時出力がファイルごとの詳細で長い。正常系は進捗の点と件数サマリだけにし、失敗時は従来どおり詳細を出す。`npm run lint` は成功時に無出力のため現状維持とする。

## 調査結果
- `package.json` のスクリプトは `"test": "vitest run"`、`"lint": "eslint ."`
- Vitest の設定ファイルは無く、既定のレポーターで各テストファイルの結果が並ぶ
- `tests/lib.test.js` はファイル先頭の `// @vitest-environment jsdom` で環境を指定している
- ESLint は成功時に何も出力しない（現状すでに簡潔）

## 実装計画
- [x] ステップ1: `vitest.config.js` を新規作成し、`test.reporters` を `"dot"` にする（`package.json` が `"type": "module"` のため ESM で書く）
- [x] ステップ2: `npm test` を実行し、成功時が点＋件数サマリだけになることを確認する
- [x] ステップ3: 一時的に失敗するテストを入れて、失敗時はファイル・行・スタックが表示されることを確認し、そのテストを削除する
- [x] ステップ4: `AGENTS.md` のテストコマンド欄に「成功時は dot レポーターで簡潔に表示する」旨を追記する

## テスト・確認方法
- [x] `npm test` が成功し、出力が簡潔になっている
- [x] 失敗時に詳細が出ることを一時テストで確認する
- [x] `npm run lint` が成功し、無出力である
- [x] `git diff` で意図した変更だけであることを確認する

## 決定事項
- テストは dot レポーター＋要約のみとし、失敗時は詳細を表示する
- lint は現状のまま（成功時は無出力）
