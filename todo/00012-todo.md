# サイトの root URL を保存する

## 概要
各記事にサイトの root URL（オリジン、例: `https://example.com:8080`）を `rootUrl` として保存する。既存データは一覧の初回読み込み時に補完し、TODO 00013 のサイト絞り込みで使う。

## 調査結果
- 記事は `{ url, hostName, title }`（お気に入りは `favorite`）。`parseHost(url)` が `https://example.com:8080` のようなオリジンを返す
- `addItem` が `hostName` を付与し、`mergeItems` は `hostName` 欠損を `parseHost` で補完している
- `storageGet` / `storageSet` で `chrome.storage.local` の配列を読み書きする
- `setupListView` が popup / フルタブ画面共通の一覧初期化を行う
- エクスポートは `read` 以外を保持し、インポートは `mergeItems` で先頭に追加する

## 決定事項
- root URL はオリジン（スキーム＋ホスト＋ポート）とし、`parseHost` の結果を使う
- 既存項目は一覧の初回読み込み時に現在の URL から計算して一括保存する
- `rootUrl` は記事データの一部としてエクスポート/インポート対象に含める

## 懸念点・未決事項
- `hostName` と `rootUrl` は現状同値で重複する。互換性のため `hostName` は残し、絞り込み・サイト順では `rootUrl` を優先する
- `chrome://` など `parseHost` が空文字を返す URL は `rootUrl` も空になる
- TODO 00011 の `normalizeItems` が先に存在している必要がある
