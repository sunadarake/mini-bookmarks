# オプション画面の中央寄せと全体の UI/UX・デザイン改善

## 概要
オプション画面が左寄せになっているため、中央寄せのカードレイアウトにする。あわせてポップアップ・フルタブ画面・オプション画面の 3 画面共通で、配色・余白・ボタン・入力欄・一覧・状態表示を整え、見た目と使い勝手を改善する。ライトテーマのみとし、現行の青系アクセントを洗練させる。

## 調査結果
- `src/options.html` は `common.css` のみを読み込み、`body` の中央寄せ指定が無いため `.container`（幅 550px）が左寄せになる
- `src/tab.html` は `tab.css` の `body { display:flex; justify-content:center }` で中央寄せしている
- `src/common.css` に 3 画面共通のスタイルがまとまっている（色・角丸・影などの変数は未使用）
- `src/lib.js` の `renderItems` は一覧が空のときに何も描画しないため、空状態の案内が無い
- オプション画面のドロップゾーンはクリックでファイル選択できるが、キーボード操作とフォーカス表示に対応していない
- `tests/lib.test.js` に `renderItems` の jsdom テストがある（空状態のテストは無い）
