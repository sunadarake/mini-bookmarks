# お気に入りボタンを見やすくする

## 概要
記事一覧の星ボタン（☆/★）は小さく薄い灰色（#ccc）で見えにくい。サイズ・色・背景を調整して、未登録と登録済みの違いが一目で分かるようにする。

## 調査結果
- 星ボタンは `src/lib.js` の `renderList` で `.star-btn`（登録済みは `.star-btn active`）として生成
- スタイルは `src/common.css` の `.star-btn` / `.star-btn.active`（font-size 14px、未登録 #ccc、登録済み #f5a623）。popup とフルタブ共通
- 挙動・DOM 構造の変更は不要。CSS のみで対応できる

## 実装計画

- [x] ステップ2: `.star-btn.active` を、オレンジの塗りと背景色で目立たせる
