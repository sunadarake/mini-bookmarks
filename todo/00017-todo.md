# お気に入り機能を削除する

## 概要
popup / フルタブ画面のお気に入り機能（星ボタン、「すべて」「お気に入り」の切替、お気に入り絞り込み）を削除する。既存の保存データに残る `favorite` プロパティはそのまま残し、データ移行は行わない。

## 調査結果
- `src/lib.js`
  - `filterItems` が `favoritesOnly` を受け取り、`favorite` で絞り込んでいる
  - `toggleFavorite` がある
  - `renderItems` が星ボタンを生成し、`onToggleFavorite` を呼ぶ
  - `setupListView` が `favoritesOnly` 状態・`setView`・表示切替ボタンのイベントを持つ
- `src/popup.html` / `src/tab.html` に `.view-switch`（すべて／お気に入り）
- `src/common.css` に `.star-btn` と `.view-switch` / `.view-btn` のスタイル
- `tests/lib.test.js` に `toggleFavorite`・お気に入り絞り込み・星ボタン・favorite 保持のテスト
- `AGENTS.md` / `README.md` にお気に入りの仕様・使い方の記述
