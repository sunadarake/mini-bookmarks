# 削除時 confirm の設定をオプションに追加

## 概要
記事削除時に確認ダイアログを出すかどうかをオプション画面で設定できるようにする。デフォルトは OFF で、確認なしに削除する。設定は popup とフルタブ画面の両方に適用する。

## 調査結果
- オプション画面は TODO 00004 で新設される（`src/options.html` / `src/options.js`）
- `src/popup.js` / `src/tab.js` の `onDelete` が `removeItem` → `storageSet` → `setBadgeText` → 再描画を行っている
- 設定を保存する仕組みはまだ無い
- `manifest.json` の `permissions` は `storage` があるため `chrome.storage.local` に設定を保存できる

## 実装計画
- [x] ステップ1: `src/lib.js` に設定キー（`MiniBookMark_Settings`）と、既定値 `{ confirmDelete: false }` をマージして返す get/set ヘルパーを追加する
- [x] ステップ2: `src/options.html` / `src/options.js` に「削除前に確認する」チェックボックスを追加し、変更時に storage.local へ保存する
- [x] ステップ3: `src/popup.js` / `src/tab.js` の `init` で設定を読み込み、`onDelete` で `confirmDelete` が true のとき `window.confirm()` を出し、キャンセルなら削除しない

## 決定事項
- confirm は popup とフルタブ画面の両方に適用する
- ブラウザ標準の `window.confirm()` を使う
- 既定値は OFF（確認なしで削除）
