# ドラッグ&ドロップで記事を並び替える

## 概要
一覧の記事をドラッグ&ドロップして位置を変更し、その順番を保存する。popup とフルタブ画面の両方で有効にする。検索中・お気に入り絞り込み中は並び替えを無効にする。

## 調査結果
- `src/lib.js` の `renderItems` が `<li class="bookmark-item">` を生成している
- 一覧は `currentItems` 配列の順で描画され、`storageSet` でそのまま保存される
- `filterItems` により描画対象は絞り込まれるが、`currentItems` 自体は全件のまま
- 記事の識別子は URL（`removeItem` / `markRead` と同じ）
- popup / tab の `render()` は `search` の値と `handlers` を渡している

## 決定事項
- 並び替えは popup とフルタブ画面の両方で有効
- 検索中はドラッグ無効
- 行全体をドラッグ可能にする

## 懸念点・未決事項
- お気に入り絞り込み中も「検索中」に準じてドラッグ無効とする
- `<a>` を子に持つ行全体ドラッグのため、テキスト選択やリンククリックとの干渉を実機で確認する必要がある
