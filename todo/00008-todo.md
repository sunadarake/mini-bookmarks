# 既読のセッション化と直前クリックのハイライト

## 概要
現在 `chrome.storage.local` に永続保存している既読状態を、ブラウザを閉じるまでの一時状態に変える。直前に開いた1件は薄いグレー背景＋チェックで強調し、それ以前に開いた項目はチェックのみ表示する。状態は popup とフルタブ画面で共有する。

## 調査結果
- `src/lib.js` の `markRead(items, url)` が `read: true` を storage.local の配列に書き込んでいる
- `renderItems` は `read` を見て `read-mark` に ✅ を出す
- 記事要素は `{ url, hostName, title, read }`（`AGENTS.md` に記載）
- `popup.js` / `tab.js` の `onOpen` が `markRead` + `storageSet` + 再描画している
- `background.js` は起動・インストール時にバッジ更新のみ
- `permissions` に `storage` があるため `chrome.storage.session` を追加権限なしで使える
- `chrome.storage.session` はブラウザ終了で自動的に消える（サービスワーカーの再起動では消えない）

## 決定事項
- 既読は `chrome.storage.session` に移し、ブラウザ終了で消える。storage.local の既存 `read` は使わない
- 直前に開いた1件は薄いグレー背景＋チェック、以前に開いた項目はチェックのみ
- popup とフルタブ画面でセッション状態を共有する

## 懸念点・未決事項
- 既存データに残る `read: true` は表示に使わない。削除マイグレーションは行わない想定
- リンククリックで popup が閉じるため、セッション保存が完了するか実機で確認が必要
- ブラウザ再起動ではなく拡張機能の再読み込みでもセッションが消える可能性がある
