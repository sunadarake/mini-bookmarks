# サイト絞り込みを select 一本化し、select 内に検索窓を追加

## 概要
現在は「サイト入力欄（`site-search`、`rootUrl` の部分一致）」と「サイト select（`site-select`、`rootUrl` の完全一致）」の2系統がある。サイト入力欄を廃止して select のみに一本化し、select を開いたドロップダウン内に検索窓を設けて、そこからサイトを絞り込んで選択できるようにする。

## 調査結果
- `src/popup.html:38-59` / `src/tab.html:36-57` に `section.site-filter` があり、`#site-search` 入力欄と `#site-select-trigger` / `#site-select-menu` を持つ
- `src/lib.js:49-66` の `filterItems` は `siteKeyword`（部分一致）と `siteUrl`（完全一致）の両方で絞り込む
- `src/lib.js:208-410` の `setupListView` が `siteKeyword` / `siteUrl` をセッションから復元・保存し、`#site-search` の input イベントで `siteKeyword` を更新している
- `src/lib.js:243-281` の `renderSiteOptions` が保存済み `rootUrl` の重複なし昇順リストで select の選択肢を生成している（先頭に「すべてのサイト」、各候補に favicon）
- `src/lib.js:360-380` で select の開閉・選択・外側クリック・Escape を処理している
- `src/common.css:64-166` に `.site-filter` / `.search-input` / `.site-select-*` / `.site-option*` のスタイルがある
- `tests/lib.test.js:85-116` に `siteKeyword` の部分一致テスト、`tests/lib.test.js:308` 付近にセッション復元のテストがある
- `AGENTS.md:36,41` と `README.md:35,49,53` にサイト入力欄（部分一致）を含む仕様が記載されている

- [x] ステップ3: `setupListView` の `siteKeyword` 状態・イベント・セッション保存を削除し、`siteUrl` のみを扱う。`DEFAULT_SESSION` からも `siteKeyword` を削除する

- [x] ステップ6: `src/common.css` の `.site-filter` / `.site-select-wrap` を select 単体向けに調整し、ドロップダウン内検索欄・候補なしメッセージのスタイルを追加する。不要になった `.site-filter .search-input` を整理する

## 決定事項
- `siteKeyword` による部分一致の絞り込みロジックは完全に削除し、絞り込みは `siteUrl`（完全一致）のみにする
- select 内検索で候補が0件のときは「該当するサイトがありません」を表示する

## 懸念点・未決事項
- ドロップダウン内検索欄の開閉時のリセット挙動は「開くたびに空に戻す」を前提とする
- 「すべてのサイト」を検索対象に含めるかは、0件時に「すべてのサイト」だけ残すのではなく候補なしメッセージを出す方針としたため、検索文字列に一致した場合のみ表示する
